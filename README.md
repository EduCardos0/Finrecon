# FinRecon – Sistema Web de Conciliação Financeira

Sistema web desenvolvido para substituir o processo manual de conciliação financeira,
eliminando a necessidade de imprimir extratos e conferir lançamentos um a um.

## O problema que resolve

Em muitos escritórios contábeis e financeiros, a conciliação bancária ainda é feita
de forma manual: extrato impresso, conferência visual, anotações em papel ou planilha.
Esse processo é lento, sujeito a erro humano e difícil de auditar.

O FinRecon resolve isso permitindo importar o extrato diretamente e realizar a
conciliação de forma estruturada, com histórico e rastreabilidade de cada lançamento.

## Funcionalidades

- 📥 Importação de transações via arquivo (CSV/OFX)
- ✅ Conciliação de entradas e saídas com status por lançamento
- 👥 Controle de clientes e parcelas
- 📊 Dashboard com métricas operacionais em tempo real
- 🔐 Autenticação com controle de acesso por usuário
- 🗂️ Histórico completo com auditoria das operações
- 📄 Exportação de relatórios em Excel e PDF
